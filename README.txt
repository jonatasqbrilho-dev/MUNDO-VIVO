# Mundo Vivo — Mapa inicial

Este é o primeiro protótipo visual do Mundo Vivo: mapa 3D em perspectiva isométrica, com floresta, rio, pedras e controles de câmera. O mundo começa sem habitantes humanos.

## Publicar gratuitamente no Netlify
1. Extraia o arquivo ZIP.
2. Acesse https://app.netlify.com/drop e entre na sua conta.
3. Arraste a pasta `mundo-vivo-mapa` para a área de publicação.
4. O Netlify publicará o mapa e mostrará um endereço `*.netlify.app`.

O protótipo usa Three.js por CDN, portanto precisa de conexão com a internet para carregar a biblioteca 3D.
